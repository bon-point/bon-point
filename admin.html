Administration Bon Point.

Gérez les demandes de créneaux, les comptes parents, les codes de connexion et les récapitulatifs de cours. L'accès est réservé à l'administrateur, avec mot de passe et code de vérification reçu par e-mail. Les paiements réels et les fonctions destinées aux familles ne sont pas encore activés.

Connexion administrateur

L'accès nécessite ton mot de passe administrateur et un code temporaire envoyé à ton adresse e-mail. Ne partage jamais ces informations. Aucun mot de passe n'est enregistré dans le code du site.

Tableau de bord

Ne renseignez que les informations nécessaires au suivi pédagogique. Le site public ne publie jamais ces documents.

Propositions de rendez-vous

Confirmez seulement les créneaux réellement libres. Les rappels sont prévus environ 48 heures avant, après confirmation et, pour les séances payantes, après paiement vérifié.

Créer ou modifier un accès parent

Générer et envoyer un code temporaire

Le code est créé sur le serveur puis envoyé directement à l'adresse du parent. Il est valable 10 minutes et ne s'affiche jamais dans cette console.

Ajouter un compte rendu de cours

Le résumé, les notions, le travail conseillé et le document PDF apparaîtront dans l'espace privé du parent concerné.

Après la création du compte rendu, un identifiant vous sera indiqué pour lui associer un PDF. Les PDF sont réservés au parent connecté ; capacité limitée pour l'instant à 700 Ko.

Glissez un PDF ici ou cliquez pour le choisir.

Derniers comptes rendus

Deux salles Discord privées

Les deux salons sont attribués uniquement aux réservations confirmées et aux cours payés, après autorisation du responsable légal. Le bot ouvre l'accès dix minutes avant la séance, puis retire son autorisation après le cours.

L'identité du participant est vérifiée lorsqu'il utilise la commande privée /lier. Le code à usage unique est envoyé directement par e-mail au responsable légal ; il n'est jamais affiché dans cette page.

Attributions et demandes de révocation

Pour une révocation urgente, le bot tente immédiatement de retirer l'accès au prochain passage planifié ; vérifiez dans Discord qu'il a bien disparu. Si la suppression échoue, retirez manuellement l'accès au salon.
